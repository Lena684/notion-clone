# Local Notes and Databases App

This repository currently contains the product and implementation blueprint
for a private, local-first notes and databases app intended to replace Notion.

Start with [`BLUEPRINT.md`](BLUEPRINT.md) for the requirements, technical
constraints, scope, deliverables, and acceptance checklist. Repository-level
guidance for implementation agents is in [`AGENTS.md`](AGENTS.md).

The application has not been implemented yet. The implementation's README must
document setup and run instructions, export behavior, and where the SQLite
database and exported Markdown files live on disk.
