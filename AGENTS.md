# Repository guidance

This repository contains the blueprint for a private, local-first notes and
databases app intended to replace Notion for personal use. Read
[`BLUEPRINT.md`](BLUEPRINT.md) before implementing or changing the product.

Keep the implementation within the blueprint's stated stack and scope. In
particular, do not add accounts, telemetry, hosting configuration, real-time
collaboration, cross-device sync, a frontend framework, or a block editor.
